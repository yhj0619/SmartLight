# 💡스마트 조명 제어 시스템

> YOLO 기반의 객체 및 상황 인식 AI 모델을 이용한 자동 조명 제어 시스템입니다. Jetson Nano와 Arduino, AWS EC2를 활용하여 효율적인 조명 관리를 구현한 프로젝트입니다.

--- 

## 📋 프로젝트 개요

이 프로젝트는 YOLO 딥러닝 기반 AI를 활용하여 객체 및 상황을 인식하고, 그에 따라 조명의 조도를 자동으로 조절함으로써 에너지를 절약하는 스마트 조명 제어 시스템입니다. <br>Jetson Nano와 Arduino를 사용해 조명을 제어하여 불필요한 전기 사용을 최소화하고 효율적인 에너지 관리를 목표로 합니다.

---

## 🔧 주요 기능

1. **객체 인식 및 상황 인식 (YOLO 기반)**  
   YOLO 기반의 AI 모델로 실시간 객체 및 상황을 인식하여 데이터를 처리하고 조명 시스템에 반영.

2. **조명 조도 자동 조절**  
   인식된 객체와 상황에 따라 조명이 자동으로 켜지고, 밝기가 조절됨.

3. **조명 조도 사용자 직접 조절**  
   사용자는 앱 내의 버튼을 통해 조명을 원하는 밝기로 수동 조절 가능.

4. **객체 및 상황 인식 (Jetson Nano 기반)**  
   Jetson Nano를 통해 객체 및 상황을 인식하는 시스템을 제공, 실시간 대응.

5. **아두이노 기반 스마트 조명**  
   Arduino를 통해 조명 제어가 가능하며, 센서 데이터를 기반으로 스마트 조명을 구현.

6. **AWS EC2를 통한 배포**  
   AWS EC2 인스턴스를 이용해 시스템을 배포하고 원격으로 접근 및 관리 가능.

1. **객체 인식 및 상황 인식**: 시스템이 실시간으로 객체와 상황을 분석하여 자동으로 조명을 제어합니다.
2. **조명 조도 조절**: 제공된 앱을 통해 직접 조명을 수동으로 조절할 수 있습니다.
3. **원격 관리**: AWS EC2에서 시스템을 원격으로 모니터링하고 관리할 수 있습니다.
